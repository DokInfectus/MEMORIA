# MEMORIA Local Data Terms

MEMORIA is a local-first memory system.

By continuing, you allow MEMORIA to read and write data inside its configured local MEMORIA storage.

This includes memory candidates, approved memories, summaries, runtime metadata, import inbox files you explicitly choose, and local MEMORIA logs.

MEMORIA will not send your chats, memories, candidates, logs, API keys, tokens, secrets, private files, model data, or runtime metadata to third-party servers.

MEMORIA will not scan private directories unless you explicitly choose an import path.

Memory candidates may be created automatically when enabled by local policy.

Durable long-term memories require your configured approval and promotion rules.

If you do not accept these terms, stop the installation.

---

# MEMORIA Lokale Datenbedingungen

MEMORIA ist ein Local-First-Gedächtnissystem.

Wenn du fortfährst, erlaubst du MEMORIA, innerhalb des konfigurierten lokalen MEMORIA-Speichers zu lesen und zu schreiben.

Dazu gehören Memory Candidates, freigegebene Memories, Zusammenfassungen, Runtime-Metadaten, ausdrücklich gewählte Import-Inbox-Dateien und lokale MEMORIA-Logs.

MEMORIA sendet keine Chats, Memories, Candidates, Logs, API-Keys, Tokens, Secrets, privaten Dateien, Modelldaten oder Runtime-Metadaten an fremde Server.

MEMORIA scannt keine privaten Ordner, außer du wählst ausdrücklich einen Importpfad.

Memory Candidates dürfen automatisch entstehen, wenn die lokale Policy das erlaubt.

Dauerhafte Langzeit-Memories folgen deinen konfigurierten Freigabe- und Promotion-Regeln.

Wenn du diese Bedingungen nicht akzeptierst, brich die Installation ab.
